# همیم کتابتون | Hamim Library

A free Pashto poetry and books website — built by BEYOND AI.

Pure HTML/CSS/JavaScript, no server needed. Pashto (RTL) first, with an
English toggle, dark mode, search, bookmarks and reading progress.

Live site: https://arman590.github.io/hamim-library/

Note: the 6 books shown are sample data.
